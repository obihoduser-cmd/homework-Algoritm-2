# Cache — шаблонный класс кэша

## Описание проекта

Программа на C++, реализующая шаблонный класс `Cache` для хранения пар «ключ — значение». Кэш позволяет добавлять и изменять значения, получать их по ключу, проверять наличие ключа и очищать хранилище.

Также программа измеряет время выполнения основных операций с помощью библиотеки `chrono`.

## Функциональность

- Добавление новых пар «ключ — значение».
- Изменение значения по существующему ключу.
- Получение значения по ключу.
- Проверка наличия ключа в кэше.
- Очистка всех сохранённых элементов.
- Вывод содержимого кэша.
- Измерение времени выполнения операций `put`, `get`, `contains` и `clear`.

## Структура программы

### Шаблонный класс `Cache`

Класс `Cache` предназначен для хранения данных разных типов благодаря использованию шаблонов C++.

**Поле:**
- `data` — вектор пар `pair<int, T>`, содержащих целочисленный ключ и значение типа `T`.

**Методы:**
- `put(int key, T value)` — добавляет новую пару в кэш или изменяет значение, если ключ уже существует.
- `get(int key, T& result)` — ищет ключ и записывает найденное значение в переменную `result`. Возвращает `true`, если ключ найден, и `false` в противном случае.
- `contains(int key)` — проверяет наличие ключа и возвращает логическое значение.
- `clear()` — удаляет все элементы из кэша.
- `print()` — выводит все ключи и соответствующие им значения.

### Функция `measureTime()`

Шаблонная функция измеряет время выполнения переданной функции.

Для работы используется библиотека `<chrono>`.

**Принцип работы:**
1. Запоминается время начала операции.
2. Выполняется переданная функция.
3. Запоминается время окончания операции.
4. Вычисляется продолжительность выполнения в микросекундах.

Возвращаемое значение имеет тип `long long`.

- `<vector>` — хранение динамического массива элементов.
- `<chrono>` — измерение времени выполнения операций.

## Принцип работы программы

1. Создаётся объект `Cache<int>` для хранения целочисленных значений.
2. В кэш добавляются три пары: `(1, 10)`, `(2, 20)` и `(3, 30)`.
3. Выводится содержимое кэша.
4. Выполняется поиск значения по ключу `2`.
5. Проверяется наличие ключа `3`.
6. В кэш добавляются ещё 5000 пар с ключами от `100` до `5099`.
7. Измеряется время выполнения 5000 вызовов каждой из операций `put`, `get` и `contains`.
8. Измеряется время очистки кэша с помощью `clear()`.
9. Выводится время выполнения каждой операции в микросекундах.

## Сложность операций

Поскольку элементы хранятся в векторе, поиск ключа выполняется последовательным перебором.

| Операция | Временная сложность |
|---|---|
| `put` | \(O(n)\) в среднем и худшем случае |
| `get` | \(O(n)\) |
| `contains` | \(O(n)\) |
| `clear` | \(O(n)\) для уничтожения элементов |

Здесь \(n\) — количество элементов в кэше. Для `put` поиск существующего ключа занимает \(O(n)\), а добавление нового элемента в конец вектора обычно выполняется за амортизированное \(O(1)\).
